# -🎙️ Basic Voice Assistant (Speak Functionality)-


This is a simple voice assistant developed for fun, featuring basic speech output functionality. Built using only HTML and CSS, it demonstrates how web technologies can be used to create interactive voice-based user experiences.

🔧 Features
Text-to-speech functionality

Minimalist UI built with HTML & CSS

Beginner-friendly code structure

📁 Technologies Used
HTML5

CSS3

Web Speech API (for speech synthesis)
